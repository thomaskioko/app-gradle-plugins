# Lint Rules

A ktlint rule set enforcing the conventions this project relies on: keeping navigation
construction inside the modules that own it, requiring the code generation annotations rather than
bindings written by hand, and naming a test after the behaviour it checks.

Full documentation, including every rule and the `.editorconfig` properties that exempt a module
from one, is on the site:

<https://thomaskioko.github.io/app-gradle-plugins/lint-rules/>

To add a rule, see the same page.
